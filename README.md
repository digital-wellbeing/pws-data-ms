# PowerWash Simulator study dataset manuscript

This manuscript describes the PWS dataset, codebook.

## Contributing

The source code of the manuscript is at https://github.com/digital-wellbeing/pws-data-ms. That source code is rendered to the PDF and Word files on our team OneDrive. To contribute:

- Clone the GitHub repo and work on the source, or
- Revise, comment and TC in the Word document (Matti will revise the source accordingly)
- Use the GitHub online text editor like a pro https://github.com/digital-wellbeing/pws-data-ms/edit/main/ms.Rmd
